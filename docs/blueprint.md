# **App Name**: Desa Digital

## Core Features:

- Authentication: Secure user authentication using email/password with role-based access control (admin, operator desa) managed by Firebase Auth.
- APBDes Summary: Display a summary of APBDes data (total pendapatan, belanja, pembiayaan) on the admin dashboard.
- Monev Monitoring: Track APBDes implementation progress (Perencanaan, Realisasi, Selesai).
- Regulations Management: CRUD operations for village regulations (Perdes, Perkades, SK) including PDF file uploads to Firebase Storage. Role-based permissions control access.
- BLT-DD Beneficiary Management: Manage KPM BLT-DD data (Nama, NIK, Alamat, Periode, Status Aktif/Tidak).
- Posyandu Data Management: Manage Posyandu data (Nama Posyandu, Nama Kader, Alamat, Jumlah Balita).
- User Management: Admin feature to add new operator desa accounts with restricted privileges.

## Style Guidelines:

- Primary color: Navy blue (#34495E) to convey professionalism and trust.
- Background color: Soft gray (#F0F4F8) for a clean and modern feel.
- Accent color: Light blue (#5DADE2) for interactive elements and highlights.
- Body and headline font: 'PT Sans', a humanist sans-serif, combining a modern look and warmth.
- Use Heroicons for consistent and clean icons throughout the application.
- Fixed left sidebar for navigation and top navbar for global actions.
- Subtle transitions and animations for improved user experience.
